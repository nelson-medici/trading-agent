# Runbook 02 · Daily Check

Tiempo: 5 min.

1. Abrir Telegram, leer alertas del día
2. Abrir portal, mirar Overview:
   - Equity vs ayer
   - Posiciones abiertas
   - DD diario/semanal/total
   - Heartbeat del engine (verde)
3. Si hay CRITICAL → runbook 05
4. Si DD diario > 3% → revisar decisiones, anotar patrón
5. Listo

## NO hacer
- Cerrar posiciones manualmente por impulso
- Agregar fondos para promediar
- Modificar límites de riesgo en caliente sin análisis
